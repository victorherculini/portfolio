## Visão Geral

Portfólio editorial combinando o design autoral original (`Fraunces` / `Instrument Serif` + `Geist` + `JetBrains Mono`) com as informações e o posicionamento atualizados de [`victorherculini`](https://github.com/victorherculini/victorherculini), além de automação real com a API do GitHub e GitHub Actions.

### Seções

- **Hero Editorial**: tipografia monumental animada linha a linha, relógio ao vivo de São Carlos (BRT), foco rotativo e contadores sincronizados com o GitHub.
- **01 · Sobre**: retrato sticky, bio animada palavra por palavra e ficha técnica completa (formação no IFSP Araraquara, mindset AI-native & stack-agnostic, áreas de atuação e status).
- **02 · Atuação & Habilidades**: os 6 pilares de foco (Web, Mobile, AI & Agents, E-Commerce, Paid Traffic e Ventures) + barras editoriais de competências.
- **03 · Processo**: workflow interativo (`01 Idea → 02 Prompt → 03 Build → 04 Ship`) com feixe animado e catálogo do que construo e opero.
- **04 · Trabalhos & GitHub Live**: projetos em destaque (alternância `Grid` / `Strip`, filtros por categoria e modal de galeria com screenshots reais) + bloco sincronizado automaticamente com todos os repositórios públicos de `@victorherculini`.
- **05 · Visão**: manifesto e 3 pilares com parallax suave (`Inovação`, `Conexão`, `Execução`).
- **06 · Contato**: canais diretos com cópia rápida de email e formulário com envio via Email ou WhatsApp.

### Automação & Experiência

- **GitHub Live Sync + GitHub Actions**: carregamento instantâneo via `data/github-snapshot.json` (atualizado diariamente pelo workflow [`.github/workflows/sync-github.yml`](.github/workflows/sync-github.yml)) + refresh ao vivo pela API do GitHub com cache de 30 min.
- **3 Temas Editoriais**: `Noir` (cobre quente), `Aurora` (deep ink + cyan) e `Paper` (claro editorial), selecionáveis na barra de navegação.
- **Bilíngue (`PT` / `EN`)** e **Command Palette (`⌘K` / `Ctrl+K`)** para navegar por seções, projetos e repositórios pelo teclado.
